#  Shopping Cart Application
A simple, interactive, and responsive **Shopping Cart** web application built using HTML, CSS, and JavaScript.
## Features
- Display available items with titles, images, and prices.
- Dynamically add products to the shopping cart.
 - Automatically updates the total price and item quantity in real-time.
 - Easily delete products or clear items from the cart.
- Optimized for both mobile devices and desktop screens.
## Technologies
 - HTML
- CSS
- JavaScript
